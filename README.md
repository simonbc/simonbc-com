# simonbc.com

My personal site, built with [Eleventy](https://www.11ty.dev/) and deployed to GitHub Pages.

## Write a post

Add a markdown file to `src/posts/`. The file name becomes the URL, so `src/posts/my-post.md` is published at `/writing/my-post/`.

```markdown
---
title: My post
date: 2026-10-10
description: One sentence summary for the page description.
draft: false
---

Post content in markdown.
```

Posts with `draft: true` show up in the local preview but are left out of the production build and the feed. `src/posts/example-post.md` is a draft you can copy.

## Preview locally

```sh
npm install
npm start
```

Then open http://localhost:8080. `npm run build` writes the production site to `_site/`.

## Deploy

Push to `main`. The GitHub Actions workflow in `.github/workflows/deploy.yml` builds the site and deploys it to GitHub Pages. `src/CNAME` is copied into the build so the custom domain stays set.

## Layout

- `src/_data/site.js`: site title, URL, description and email
- `src/_data/offer.js`: the offer copy (steps, pricing, next step), shared by the home and Work with me pages
- `src/_includes/`: layouts and partials
- `src/css/style.css`: all styles; the JetBrains Mono font is self-hosted from `@fontsource-variable/jetbrains-mono`
- `src/index.njk`, `src/work.njk`, `src/writing.njk`, `src/about.md`: pages
- `/feed.xml`: Atom feed, generated by `@11ty/eleventy-plugin-rss` (configured in `eleventy.config.js`)
